# 🧠 olimpiada-python

> *"Every expert was once a beginner."*

I'm **Michaell**, a 2nd-year student of Microcomputer Systems and Networks (SMR) in Gran Canaria.
In October 2026 I had never seriously written a line of code.
This repository is my journey from zero to the **Informatics Olympiad of Las Palmas 2027** — one problem at a time.

---

## 🎯 The goal

- Learn Python from scratch.
- Solve olympiad-style problems: logic, loops, strings and algorithms.
- Compete in the **Olimpiada Informática de Las Palmas (OILP)** in January 2027.
- Keep going, whatever the result.

## 📏 My rules

1. **Struggle first.** At least 30 minutes on a problem before looking at any solution.
2. **The output must be exact.** A judge compares every character — so do I.
3. **Commit every study session.** Consistency beats talent.
4. **Every mistake is a lesson.** I keep the bugs I learn from.
